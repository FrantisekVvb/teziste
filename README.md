# Těžiště

Interaktivní simulace: útvar se zavěsí na kolečko a natočí se tak, aby jeho těžiště viselo svisle pod bodem závěsu.

## Spuštění lokálně

```bash
cd teziste
npm start
```

Aplikace poběží na adrese **http://localhost:3482**.

Alternativa bez Node.js:

```bash
python3 -m http.server 3482
```

## Ovládání

- Přetáhni červený útvar a pusť ho, když je díra u kolečka — útvar se zavěsí
- Zavěšený útvar můžeš rozhoupat tažením
- Zavěšený útvar sundáš chycením díry na kolečku a tažením dolů
- **Sundat** vrátí útvar do výchozí volné polohy
